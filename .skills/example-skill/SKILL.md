## Skill: Example Skill

This is an example skill that demonstrates how to create a skill for SyntaxAI.

### Usage
- Mention any of the triggers: "مثال", "skill example", "example skill"
- SyntaxAI will include this skill context in the prompt

### What This Skill Does
This skill shows the format and structure of a SyntaxAI skill file.

### Configuration
Skills are YAML frontmatter with markdown body content.

### Example Commands
- `read_file` - Read a file
- `shell` - Execute a shell command
- `git_status` - Check git status
